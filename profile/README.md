# Nimos Websites

**We make websites** — built, launched and run for you, from Kelowna, BC.
→ **[nimoswebsites.com](https://nimoswebsites.com)**

Nimos is a small studio amplified by an in-house agent workforce. The same engines that
build client sites run the whole company — this org is that machinery, open where it
makes sense and private where it is ours.

## Platform
- **[nimos](https://github.com/Nimos-Websites/nimos)** — the AI workforce OS: cockpit, fleets, pipelines
- **[gantry](https://github.com/Nimos-Websites/gantry)** — the build engine: doctor → plan → build → audit → ship
- **[fleet](https://github.com/Nimos-Websites/fleet)** — the agent fleet runtime
- **[godsource](https://github.com/Nimos-Websites/godsource)** — the ground-truth knowledge layer
- **[nimos-cockpit](https://github.com/Nimos-Websites/nimos-cockpit)** — the operator console

## Products
- **[motion-menu](https://github.com/Nimos-Websites/motion-menu)** — 597 live motion patterns for AI-built sites · [motionmenu.ca](https://motionmenu.ca)
- **[plinth](https://github.com/Nimos-Websites/plinth)** — fixed-scope website builds, sold at three prices
- **[media-forge](https://github.com/Nimos-Websites/media-forge)** — desktop app for the open-source AI film stack
- **[nimoswebsites-app](https://github.com/Nimos-Websites/nimoswebsites-app)** — the studio's own site and pipeline
